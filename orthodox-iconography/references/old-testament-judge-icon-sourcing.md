# Old Testament judge icon sourcing pattern

Use this when adding Orthodox or Eastern Christian icon assets for Old Testament judges in Bible-study guides.

## Search pattern

1. Search for true iconographic sources before settling for Western biblical artwork.
2. Wikimedia Commons is useful for source-clear icon candidates. Use targeted searches such as:
   - `Gideon icon`
   - `Deborah prophetess icon`
   - `Righteous Deborah`
   - `Samson icon`
   - Russian/Cyrillic variants when relevant.
3. Filter aggressively. Do not treat these as Orthodox icons:
   - Western print series labeled `Icones ...` in Latin/Dutch metadata.
   - Unrelated saints with the same name, e.g. St Samson of Dol rather than Samson son of Manoah.
   - Logos, PDFs, modern portraits, or generic artwork.

## Source-clear examples from the Judges pass

Good reusable iconographic assets found:

- `File:Gideon.jpg` — Judge Gideon, Russian Orthodox icon, first quarter 18th century, iconostasis of Kizhi monastery, Karelia, Russia; public domain.
- `File:Righteous_Deborah.jpg` — Russian Orthodox roundel of Righteous Deborah from an icon depicting Old Testament women; public domain.
- `File:Samson_Fighting_the_Lion_(18th_c.,_Kargopol_style).jpg` — Russian icon painting, first half 18th century, Kargopol region; public domain.

Do not overstate. In that pass, no source-clear Orthodox icons were added for Barak, Jephthah, Othniel, or Ehud; reusable results were Western print series or unrelated material.

## Captioning rule

- Label true icons plainly as Orthodox/Russian icon/iconographic assets when source metadata supports it.
- Label Western artwork as illustrative artwork, not Orthodox iconography.
- For morally difficult passages, keep captions sober and avoid heroic, sensational, or violent framing.

## Verification rule

After adding icon assets to a Bible-study project:

1. Store files in the book-local `Assets/` folder.
2. Embed with Markdown image syntax: `![Alt](Assets/file.jpg)`.
3. Update the visual manifest and resources note.
4. If an audit note contains visual counts, update counts after recalculating local assets, manifest entries, and active-guide image references.
5. Run image-open validation, guide verifier, image-link resolution, and broken-link scan before reporting completion.
