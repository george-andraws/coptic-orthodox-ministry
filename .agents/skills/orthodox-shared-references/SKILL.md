# Orthodox Shared References

This is a passive, portable reference library. It does not replace a primary lesson, exegesis, or iconography skill. Read only the individual reference relevant to the task.

## Reference map

- `references/patristic-sources.md` and `references/patristic-sourcing-policy.md`: verify attribution and source status.
- `references/source-confidence.md`: classify and state confidence honestly.
- `references/bible-study-guide-structure-standard.md` and `references/bible-study-quality-contract.md`: structure and audit substantial study guides.
- `references/lexical-and-translation-depth-standard.md`: use language study responsibly.
- `references/orthodox-depth-bar.md` and `references/spiritually-edifying-exegesis-voice-standard.md`: preserve spiritual depth and readable prose.
- `references/orthodox-literary-voice-synthesis.md`: write beautiful source-aware prose without imitation.
- `references/orthodox-visual-assets.md`: source, license, caption, and visual-theology practices.
- `references/coptic-lessons-publication-schema.md` and `references/orthodox-artifact-production.md`: keep public Markdown structured and portable.
- `references/coptic-treasures-source-map.md`: discover Coptic Orthodox sources while respecting their terms and copyright.

Do not assume access to private repositories, local databases, personal schedules, licensed software, cloud documents, or delivery services. Do not redistribute licensed materials. Public output should preserve sources, uncertainty, and reusable Markdown rather than private production machinery.
