# Orthodox Content Routing

## Scope before routing

For existing Bible studies, revision is the ordinary mode. Resolve the actual target and scope before research or writing; inspect the existing project brief or handoff for an unspecified continuation. New-book planning, scaffolding, and missing-guide creation require explicit new-work scope or verified absence. Review or recommendation does not authorize saving, collateral edits, media regeneration, or publication.

## Routing table

- **Full biblical book Bible study:** use a book-level project plan to resolve scope, existing guides, and session sequence. Apply `orthodox-shared-references` for common standards and `orthodox-biblical-explanation` for passage-level interpretation. These supporting resources do not replace book-level planning.
- **Single existing Bible-study guide revision:** read the whole baseline, preserve its strengths, and apply the shared quality contract. Use `orthodox-biblical-explanation` when interpretation needs work; request visual or source research only when material and in scope.
- **Single new or verified missing session guide:** resolve the exact passage and its place in the book project first, then use the shared guide standards with `orthodox-biblical-explanation`. Do not duplicate an existing guide.
- **Orthodox lesson, adult meeting lesson, feast/fast lesson, saint lesson, article, or reflection:** primary `coptic-orthodox-spiritual-lessons`.
- **Passage explanation only:** primary `orthodox-biblical-explanation`. It supports lessons and Bible studies but does not take over their full deliverables when only explanation is requested.
- **Apocalyptic passage requiring specialized interpretation:** use `orthodox-apocalyptic-exegesis` for the specialized interpretive method, within the scope of the requested deliverable.
- **Lectionary question only:** consult authoritative Coptic lectionary sources and verify the day, service, edition, and passage boundaries. Distinguish an actual reading appointment from thematic resonance.
- **Icon/image interpretation only:** primary `orthodox-iconography`.

## Ambiguity rules

- If a request names a whole biblical book and asks for a Bible study, resolve the book-level plan before drafting a single lesson.
- If a request asks for a lesson, use `coptic-orthodox-spiritual-lessons`.
- If a request includes both a lesson and a biblical passage, the lesson workflow owns the deliverable and passage explanation supports it.
- If a request explicitly covers a whole biblical book, keep that book-level scope even when the wording includes “lesson.”
- Supporting resources supply facts and method. They do not decide the final artifact shape.

## End-user examples

- “Create an Orthodox lesson on the Fast of the Apostles” → `coptic-orthodox-spiritual-lessons`.
- “Draft the next Amos Bible-study session” → inspect the existing book project, resolve the target session, and use shared guide standards with passage-level explanation.
- “Create a full Orthodox Bible study on Amos” → inspect existing work first; begin new-book planning only for explicitly new work or a verified gap.
- “Improve the existing Amos guide” → bounded revision, not new-book planning or a new-project questionnaire.
- “When is Amos 5 read in the Coptic lectionary?” → verify the appointment against authoritative lectionary sources.
